かずの ごうせい と ぶんかい — PWA版

【設置方法】
1. このZIPを展開します。
2. 展開したフォルダー内の全ファイルを、同じ構成のままHTTPS対応のWebサーバーにアップロードします。
3. index.htmlのURLをブラウザーで開き、「オフラインでも あそべる準備ができました。」と表示されるまで待ちます。
4. 対応ブラウザーでは「ホーム画面に追加」ボタンを利用できます。
   iPhone・iPadではSafariの共有メニュー →「ホーム画面に追加」を選択してください。
   ブラウザーによってはメニューに「アプリをインストール」等が表示されます。

【ローカルでの動作確認】
このフォルダーで「python3 -m http.server 8000」を実行し、
http://localhost:8000/index.html を開きます。
HTMLファイルのダブルクリック（file://）では、PWAのインストール・オフライン保存は動作しません。
スマートフォンからアクセスする場合はHTTPSで配信してください。

【オフライン】
初回はインターネット接続が必要です。準備完了後は、数の問題・画面表示・電子音をオフラインで利用できます。
日本語の読み上げは、端末にインストールされている音声とブラウザーの対応状況によります。
ブラウザーのサイトデータを消去した場合は、もう一度オンラインで開いてください。

【更新】
変更したファイルを配信する際は、sw.js内のCACHE_VERSIONも v2、v3… と変更してください。
更新を検出すると「最新版に更新」ボタンが表示されます。押すと画面が再読み込みされ、問題は最初から始まります。
アプリを開き直すか、別の画面から戻ると更新を確認します。
同じアプリを複数のタブで開いている場合、更新時にそれらのタブも再読み込みされます。

【構成】
index.html                 学習画面（元のHTMLを修正）
styles.css                 外部CDN不要のローカルCSS
manifest.webmanifest       アプリ名・起動URL・アイコン設定
pwa.js                     インストール案内・オフライン準備・更新処理
sw.js                      全ファイルのオフライン保存
icons/                     192px・512px・maskable・Apple用アイコン

設置先のサブフォルダーにも対応しています。
Webサーバーがsw.jsをJavaScriptとして配信するようにしてください。
manifest.webmanifestはapplication/manifest+json（またはapplication/json）として配信してください。
sw.jsにはCache-Control: no-cacheの設定を推奨します。
